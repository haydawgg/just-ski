# Skier cloth material source

`technical_ripstop_albedo_512.png` was generated for this project with
OpenAI's built-in image generation tool on 2026-09-10 and downsampled from the
source output to 512 x 512.

The prompt requested a seamless, near-white grayscale technical-shell fabric
with a fine woven ripstop structure, no folds, logos, text, directional light,
or color cast. Jacket, pants, and glove colors multiply this neutral albedo.
Local triplanar projection keeps the texture stable on both the authored body
regions and generated clothing shells without requiring shared UV coverage.
