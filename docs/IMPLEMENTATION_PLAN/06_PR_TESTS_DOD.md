# 16. Prohibited shortcuts

| **Shortcut**                                                                     | **Why it is not acceptable**                                                                                      |
|----------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------|
| Raise maximum camera distance dramatically                                       | Hides target-relative fallback failure and weakens composition.                                                   |
| Flatten/move the problematic crest before fixing camera                          | Removes reproduction instead of fixing camera safety.                                                             |
| Disable camera collision                                                         | Trades target loss for terrain clipping.                                                                          |
| Use camera shake/huge FOV to sell speed                                          | Masks lack of parallax and can worsen jump comfort.                                                               |
| Narrow physics probes only to fix stance                                         | Risks ground/contact stability; presentation needs its own width.                                                 |
| Force a trick/tuck pose in straight air                                          | Does not solve no-trick athletic baseline.                                                                        |
| Globally slow animation blends                                                   | Can make input feel mushy; separate impact response from state ownership.                                         |
| Double particle counts                                                           | Does not fix wrong emitter ownership/contact placement/timing.                                                    |
| Darken all snow                                                                  | Does not restore local form/shadow architecture.                                                                  |
| Delete guide strips without replacing terrain readability                        | Removes a symptom but can make gameplay worse.                                                                    |
| Delete StepDownTable without metadata migration                                  | Can break stable spots/challenges/content tracking.                                                               |
| Require one giant tree batch after redesign                                      | Preserves the spatial LOD limitation.                                                                             |
| Replace ParkLayout with hand-authored one-off jumps                              | Throws away existing trajectory-aware architecture.                                                               |
| Delete telemetry/debug tooling for release cleanliness                           | Release should hide tooling by default, not remove it.                                                            |
| Treat MJPEG repeated frames as physics stutter                                   | Known recorder behavior can create false positives.                                                               |
| Approve fine materials from 960×540 MJPEG                                        | Insufficient evidence for thin edges/AA/microtexture.                                                             |
| Use different manual inputs for before/after acceptance                          | Run-to-run variation can be mistaken for an implementation improvement; use the canonical deterministic artifact. |
| Add an acceptance test but omit it from the executable gate                      | The file may never run in normal QA, creating false confidence.                                                   |
| Approve visual/world improvements while ignoring declared performance regression | A prettier frame is not a release improvement if the target performance contract is broken.                       |
| Fix a blocking out-of-scope issue inside an unrelated phase diff                 | It destroys change-family isolation; use the narrow dependency exception and a separate regression-backed change. |
| Validate camera only at one resolution/aspect ratio                              | Absolute pixel behavior can hide composition/UI failures at other supported viewport shapes.                      |

# 17. Definition of done

| **Area**                 | **Done when...**                                                                                                                                                                                                                                                                                                                      |
|--------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Camera correctness       | The skier cannot be lost because collision/fallback leaves the camera behind. Crest, destination-overlap and reacquire regressions pass at multiple rates.                                                                                                                                                                            |
| Camera feel              | Takeoff/landing are continuous in screen position and scale; ground turns have modest directional lead; no excessive shake/FOV pumping.                                                                                                                                                                                               |
| Character                | Visual stance is decoupled from physical probe width; neutral skiing is athletic; straight air is compact/active; landings prepare/compress/rebound naturally.                                                                                                                                                                        |
| Skis/poles/contact       | Outside-ski loading and edges read; poles support silhouette; tracks/spray/landing burst and altitude shadow are physically placed and timed.                                                                                                                                                                                         |
| Course                   | Three hero jumps increase in size and provide real preparation time; optional jib/advanced content does not clutter the center line; stable content contracts are preserved/migrated; nominal and recorded off-nominal speed/approach sweeps remain recoverable; end-to-end content/finish smoke is documented.                       |
| Terrain                  | Hero jumps look sculpted into continuous snow; seams are concealed; visible and collision terrain agree in active interaction zones.                                                                                                                                                                                                  |
| Snow/lighting            | The piste reads as snow rather than gray concrete; directional/local form is visible without crushing brightness; low-angle lighting remains stable.                                                                                                                                                                                  |
| World                    | Trees/mountains have structural variation; depth layers are clear; resort infrastructure/parallax make speed and scale believable; static frames remain convincing; final dressing does not introduce persistent chase-camera occlusion on canonical or edge-of-lane sweeps.                                                          |
| Performance/presentation | Canonical-run whole-game profiling meets the named target contract or is explicitly provisional when no shipping target exists; reflection-probe policy is evidence-based; representative display/aspect and actual SDR/HDR paths are validated; quality gates pass; final UI/capture contains only intentional release presentation. |
| Evidence                 | Automated tests, before/after metrics and native/lossless visual captures support every major sign-off; canonical trace/version and effective display state are recorded; new fixtures are registered in executable gates; no model claims a visual PASS it could not actually inspect.                                               |
| Regression preservation  | All earlier phase gates plus the Phase 13 cross-state preservation matrix remain at least as strong as the Phase 0 baseline; any newly introduced unrelated failure is resolved or remains a STOP.                                                                                                                                    |
| Out-of-scope systems     | Audio and unrelated scoring/controls/persistence/challenge/settings behavior are not opportunistically redesigned; their existing acceptance remains green unless a separately documented blocking exception was required.                                                                                                            |
