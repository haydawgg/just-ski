# Historical Documents

This directory preserves completed plans, dated QA reports, and superseded roadmaps that are useful as implementation and decision history but are no longer active task lists.

Do not treat unchecked items in these files as current work. Current direction is tracked in the top-level `docs/` documents, especially:

- `../CONTENT_DESIGN_PLAN.md`
- `../PERFORMANCE_BACKLOG.md`
- `../KNOWN_ISSUES.md`
- `../CONTROLLER_VALIDATION.md`
- `../PRODUCTION_SKI_RUN_QA.md`

Archived records:

- `FINISH_PLAN_2026-09-01.md` — stabilization/modularization completion plan; most implementation work landed before archival.
- `TRICK_REALISM_PLAN_2026-09-01.md` — mechanical trick-realism redesign plan; the mechanical redesign is implemented, leaving empirical feel/QA work.
- `GAMEPLAY_CLIP_ISSUE_REPORT_2026-08-30.md` — QA report for a specific older gameplay clip/build state.
- `PERFORMANCE_ROADMAP_2026-09-02.md` — original performance investigation and phased roadmap, including historical evidence and rejected proposals.

Git history remains the authoritative record of when these documents were created and changed.
